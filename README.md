# 行动代号 · 家庭桌

面向同一台设备当面游玩的中文游戏，自带 526 个中文词，无需登录。支持安装到桌面、离线游玩和自动保存对局。

## 在线打开与安装

发布地址：**https://xiaoyaoth.github.io/codenames/**

- **iPhone / iPad**：用 Safari 打开，点击「分享」→「添加到主屏幕」。
- **安卓**：用 Chrome 打开，点击页面底部的「安装到桌面」，或浏览器菜单中的「安装应用」。
- **电脑**：使用 Chrome / Edge 地址栏的安装按钮；Safari 可通过「文件」→「添加到程序坞」安装。

首次联网打开，等待页面显示「离线就绪」后，就可以断网再次打开。浏览器清理网站数据后，需要联网重新缓存。安装入口也提供各平台的操作说明。

有新版本时，页面底部会出现「更新应用」。点击后才刷新并启用新版本，正在进行的对局会从本地保存中恢复；不会在游戏过程中自动刷新。

## 下载后直接打开

解压 `行动代号-家庭桌.zip`，双击其中的 `index.html` 即可离线玩。游戏主体仍在这个 HTML 文件内，复制它到另一台设备也能玩。直接打开本地文件时不提供 PWA 安装；安装需要使用上面的 HTTPS 网站或本地预览服务器。

## 同一台设备怎么玩

1. 分成红蓝两队，每队选一位队长，其余人负责猜词。推荐 4 人以上；3 人可以由一人同时担任两队猜词者。
2. 点击「开始一局」，选择先手和词库；未指定词库时使用默认词库。
3. 队长需要看身份时，点击「队长查看密钥」，其他人移开视线。查看后点击「隐藏密钥，返回棋盘」。
4. 队长直接口述提示词和关联数量，网页无需输入或选择任何提示信息。
5. 队员点击卡片并确认翻牌，自行掌握猜词次数。结束时点击「结束本轮，交给红队／蓝队」，直接切换到对方回合。

只有队长可以查看密钥。切换窗口、切换标签页或刷新页面后，队长视角会锁定，再次确认才能查看。

## 选择与新建词库

点击顶部「词库」，或新对局中的「选择词库」，可以选择默认词库或已保存的词库。词库选择只影响新对局，不会替换正在玩的棋盘。

点击「新建词库」，填写名称并粘贴词语，然后点击「保存并选择词库」。中文逗号、英文逗号、空格、换行、Tab、顿号和中英文分号都能分隔词语，也可以混用。重复词会自动去除；保存时需要至少 25 个不同的词，每个词最多 8 个字，词库名称不能重复。

自建词库保存在当前浏览器或应用中，刷新后仍可重新选择。清理网站数据会删除本机词库；不同设备与浏览器之间不自动同步。

## 本版家庭规则

- 25 张代号卡：先手队 9 名特工、后手队 8 名特工、7 名路人、1 名刺客。
- 提示词和数字都由队长口述。按数字 N，通常最多猜 N＋1 张，由大家自行掌握。
- 网页只记录各轮翻牌结果，不记录提示词和数量，也不限制翻牌次数。
- **猜到路人或对方特工，有剩余机会就能继续猜。**
- 对方特工计入对方进度，路人不增加任何队伍进度。
- 红蓝轮次由队员点击按钮手动切换；翻到路人、对方特工或翻牌次数增多，都不会自动换队。
- 猜到刺客立即输；任何一队找齐全部特工立即赢，包括对方误点你的最后一名特工。
- 0 表示没有词与提示相关，「无限」不告知关联数量；这些提示也直接口述，换队由队员决定。
- 提示不得与未翻开的代号词完全相同。谐音、拆词、成语等尺度由家人开局约定。

## 保存与离线

支持本地保存的浏览器会自动保存当前对局。使用相同浏览器、相同网址或文件路径再次打开可继续；部分浏览器或隐私模式限制本地保存时，会在页面底部提示。已有对局也会保留棋盘和翻牌记录，切换为手动换队流程。

不同浏览器、设备和网址之间不自动同步对局。本地文件、GitHub Pages，以及部分系统的已安装应用可能使用不同的存储空间。

可选的本地预览方式：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

在本目录运行后打开 `http://127.0.0.1:8765`。游戏仍只在设备本地运行。

## 发布与维护

GitHub Pages 从 `main` 分支根目录发布静态文件。`manifest.webmanifest` 使用相对路径，支持 `/codenames/` 这样的部署子路径。`sw.js` 缓存游戏页面、脚本和图标，不需要外部字体、接口或 CDN。

修改应用文件时同步修改 `sw.js` 中 `CACHE_NAME` 的版本后缀，确保旧安装能检测到新版本。缓存优先保证断网启动及同一版本的资源一致性；新版本缓存完整后，等待玩家手动更新。
