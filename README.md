# 行动代号 · 家庭桌

双击 `index.html`，用浏览器打开即可玩。整个游戏在一个文件内，自带 500 多个中文词，无需联网、安装或登录。也可以将这个文件复制到另一台设备。

## 同一台设备怎么玩

1. 分成红蓝两队，每队选一位队长，其余人负责猜词。推荐 4 人以上；3 人可以由一人同时担任两队猜词者。
2. 点击「开始一局」，选择先手；也可以粘贴自定义词库。
3. 把设备交给当前队长，其他人移开视线。队长确认后查看密钥。
4. 队长输入「一个词＋一个数字」，提交后密钥立即隐藏，再把设备交给猜词者。
5. 猜词者点击卡片并确认翻牌。机会用完或主动结束后，将设备交给另一队队长。

只有队长可以查看密钥。切换窗口、切换标签页或刷新页面后，队长视角会锁定，再次确认才能查看。

## 本版家庭规则

- 25 张代号卡：先手队 9 名特工、后手队 8 名特工、7 名路人、1 名刺客。
- 提示数字为 N 时，最多猜 N＋1 张，每翻一张都消耗一次机会。
- **猜到路人或对方特工，有剩余机会就能继续猜。**
- 对方特工计入对方进度，路人不增加任何队伍进度。
- 至少猜一张才能主动结束。机会用完自动换队。
- 猜到刺客立即输；任何一队找齐全部特工立即赢，包括对方误点你的最后一名特工。
- 提示为 0 或「无限」时不限次数，至少猜一张才能主动结束。0 表示没有词与提示相关。
- 提示不得与未翻开的代号词完全相同。谐音、拆词、成语等尺度由家人开局约定。

## 保存与离线

支持本地保存的浏览器会自动保存当前对局。使用相同浏览器、相同文件路径再次打开可继续；部分浏览器或隐私模式限制本地保存时，会在页面底部提示。队长未提交的提示不会保存。

可选的本地预览方式：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

在本目录运行后打开 `http://127.0.0.1:8765`。游戏仍只在设备本地运行。
